# Simple Calculator in C

A simple menu-driven calculator developed in C.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling

## Technologies Used
- C Programming
- GCC Compiler
- Visual Studio Code

## How to Run

Compile the program:

```bash
gcc calculator.c -o calculator
```

Run the program:

```bash
./calculator
```
